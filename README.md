# Predictive-Modeling-Housing-Prices-Regression
Flujo de Ciencia de Datos y Machine Learning sobre el dataset House Prices de Kaggle. Implementa preprocesamiento masivo, PCA, K-Means, modelos Ridge, Lasso, Random Forest y Redes Neuronales para predecir precios de viviendas, optimizando la precision y evaluando la interpretabilidad en tasaciones.
